# MetaCom 2027

Static conference website for the 2027 edition of the International Conference on Metaverse Computing, Networking and Applications.

## Preview / deployment

The site is plain HTML, CSS, and JavaScript. No build tools or package installation are required.

To publish with GitHub Pages:
1. Open the repository settings.
2. Go to Pages.
3. Select Deploy from a branch.
4. Choose the main branch and the root folder.
5. Save. GitHub Pages will publish index.html.

## Content notes

- The research scope is adapted from the MetaCom 2026 conference description.
- The site is explicitly for MetaCom 2027 and does not reuse 2026 dates, organizers, fees, speaker details, or submission instructions.
- 2027 dates, submission deadlines, portal, review details, program, committee, and publication arrangements are marked as to be announced until confirmed.
- Venue details identify Yeshiva University Museum at 15 West 16th Street, New York, NY 10011.
